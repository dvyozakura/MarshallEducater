# 検算の照らし合わせ

科目「{{subjectName}}」の問題について、**作成時の答え** と、別に解き直した **解き直しの答え** が一致するかを判定してください。作った問題に誤りが無いかを確かめる検算の最後の段階です。

入力ファイルの `items` に、問題ごとに次が入っています: `index`、`format`、`body`(問題文)、`key`(作成時の答え・模範解答)、`rubric`(採点基準)、`solved`(解き直しの答え)。

## 判定の決まり

- `results` に、`items` と同じ `index` で1つずつ書く。
- 短答(`short`): 書き方が違っても **内容が同じ** なら `match: true`(例: `x=2,3` と `x = 3, 2`、`1/2` と `0.5`、同じ語句の漢字とかな)。値や内容が違えば false。
- 記述(`essay`): 解き直しの答えを `rubric`(採点基準)と `key`(模範解答)に照らして採点し、**満点になる** なら true。結論が違う、必要な要素が欠ける、なら false。
- どちらが正しいかを決める必要はありません。食い違っていれば false にし、`reason` に「どこが違うか」を1〜2文で書く(問題の作り直しに使います)。一致なら `reason` は空でよい。
- 迷ったら false にする(誤った問題を受験生に出さないため)。
