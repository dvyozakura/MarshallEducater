# 授業ノート

科目「{{subjectName}}」の単元「{{unitName}}」の **授業ノート** を書いてください。受験生が教科書の代わりに読んで、この単元をひととおり理解し、入試問題に取りかかれる水準を目指します。

入力ファイルの内容:

- `project` … 志望校・試験の型・目標の高さ。
- `unit` … この単元(`id`、`name`、上位の単元を含む `fullName`)。
- `siblings` … 同じ科目のほかの単元の名前(このノートでは扱わない。重なりを避けるための参考)。
- `weakness` … この単元の苦手の記録(習熟度 0〜100、ミスの種類ごとの回数)。まだ記録が無ければ null。
- `mistakes` … この単元で受験生が実際に間違えた問題と、採点時の所見(無ければ空)。
- `trend` … 志望校の傾向(頻出単元、難易度の所見)。無ければ null。
- `previous` … 前に作ったノート(作り直しのとき)。無ければ null。

## ノートの構成(Markdown。`markdown` に入れる)

1. `# {{unitName}}` で始める。
2. `## 要点` … 定義・公式・定理・重要事項を、意味や使いどころと一緒にまとめる。丸暗記の一覧にせず、「なぜそうなるか」を短く添える。
3. `## 例題` … 基本 → 標準 → 目標校レベルの順に 2〜4 題。それぞれ **問題 → 考え方 → 解答** を書く。例題は自分で作る(実在の入試問題や市販教材の文章を写さない)。
4. `## よくある誤り` … 受験生がしがちな間違いと、その防ぎ方。`weakness` や `mistakes` があれば、この受験生の実際のミスに合わせて書く。
5. `## 確認問題` … 自分で解ける短い問題を 2〜3 題と、最後にその答え。

## 決まり

- 内容の正確さを最優先する。公式・事実・計算は確かめてから書く。あいまいな点は書かない。
- 数式は LaTeX(`$...$`、`$$...$$`)。図が必要なところは、文章で位置関係を説明する。
- 長さの目安は 1500〜4000 字。志望校の傾向(`trend`)があれば、その形式で問われやすい点を「要点」に一言添える。
- `previous` があるときは、良い部分を残しつつ、苦手の記録に合わせて直す。
