# 入出力の約束(必ず守ること)

ME_PROMPT_KIND: {{kind}}
ME_INPUT_FILE: {{inputFile}}
ME_OUTPUT_FILE: {{outputFile}}

- 上のパスは、いまの作業フォルダからの相対パスです。
- ME_INPUT_FILE が「なし」でなければ、最初に Read ツールでそのファイルを読んでください。
- 結果は、ME_OUTPUT_FILE のパスに Write ツールで **JSON ファイルとして** 書いてください。JSON 以外の文字(説明文、コードブロックの記号 ``` など)をファイルに入れないでください。
- 文字コードは UTF-8。文字列の中の改行は `\n`、バックスラッシュは `\\` と書きます(LaTeX の `\frac` は JSON では `\\frac`)。
- 指示されたファイル以外は書き換えないでください。コマンドの実行やインターネットの利用はしません。
- JSON は次の JSON Schema に合わせてください(項目名・型・必須かどうかを守る)。

```json
{{schema}}
```

- 書き終えたら、返答は「完了」とだけ書いてください。
