# 志望校の出題傾向のまとめ

科目「{{subjectName}}」について、この受験生の志望校({{university}} {{faculty}})の **出題傾向** をまとめてください。材料は、受験生が取り込んで内容を確かめた(確定した)過去問です。

入力ファイルの内容:

- `project` … 志望校・試験の型・目標の高さ。
- `sources` … 確定した過去問の一覧。それぞれ `title`、`pageCount`、`problems`(設問ごとの `number`・大問 `major`・小問 `minor`・配点 `points`・解答の形式 `answerFormat`・推定の単元 `unitName`・本文の冒頭 `bodyHead`・選択肢の数・図の数)。
- `units` … この科目の単元の一覧(`id`、`name`)。
- `previous` … 前回まとめた傾向(初めてなら null)。過去問が増えたので、これを土台に **更新** する。

## まとめる内容

- `format` … 出題形式(例: 「全問マーク式」「記述式中心。大問ごとに小問が誘導になっている」)。
- `structure` … 大問構成。大問ごとに `label`(例: 「第1問」)と `description`(分野・形式・小問の数・配点の目安)。年度によって違う場合は、典型的な形を書き、違いは説明に添える。
- `frequentUnits` … 頻出単元。`unit` は入力の `units` の `name` に合わせ、`note` に出方(毎年出る、融合で出る、など)を書く。よく出る順に。
- `volume` … 分量(大問・小問の数、文章や計算の量)。
- `timeAllocation` … 時間配分の目安(試験時間が分かればそれに対して、大問ごとに何分か)。分からない場合は、分量からの推定であることを明記する。
- `difficulty` … 難易度の所見(標準的な問題と差がつく問題の割合、目標の高さに対してどこで点を取るべきか)。
- `summaryMd` … 受験生が読むまとめ(Markdown、見出しと箇条書きで 300〜800 字)。対策の方針(何を優先するか)まで書く。

## 決まり

- **入力の過去問に書かれていることだけ** をもとにする。この大学について記憶している一般的な知識で補わない(年度が違ったり誤っていたりするため)。材料が少ないとき(1年分だけ、など)は、その旨と「まだ確かなことは言えない点」を `summaryMd` に書く。
- 過去問の文章をそのまま長く引用しない。
