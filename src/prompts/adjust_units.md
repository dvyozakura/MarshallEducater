# 単元ツリーの調整

科目「{{subjectName}}」の単元ツリー(学習項目の一覧)を、この受験生の目標に合わせて調整してください。

入力ファイルには、プロジェクトの設定(志望校・試験の型・目標の高さ・試験日)、いまの単元ツリー(`tree`)、志望校の傾向(`trend`。まだ無ければ null)が入っています。

## やること

- 志望校と試験の型で **出題されない・ほとんど出ない単元** は、重み `weight` を 0 にする(消さずに 0 にする)。
- **よく出る・配点が大きい単元** は重みを 2(重点)か 3(最重点)にする。ふつうは 1。
- 目標に対して **足りない単元** があれば追加する(例: 融合問題、志望校に特有の形式)。細かすぎる単元は親にまとめてよい。
- 傾向(`trend`)があれば、頻出単元を重みに反映する。

## 決まり

- すでにある単元の `id` と `name` は変えない(記録と結び付いているため)。追加する単元の `id` は、ほかと重ならない新しい文字列(例: `u03-90`)にする。
- 階層は2段(大きな単元 > 小さな単元)を基本とし、深くても3段まで。
- `weight` は 0〜3 の数。
- `note` には、何を増やし、何を減らし、どこを重点にしたかを、受験生に向けて3〜6文で書く。
- 教科書や市販教材の文章を写さない。単元名は短い見出しにする。
