# 教材の修正(点検の指摘を反映)

科目「{{subjectName}}」の教材「{{chapterTitle}}」の文章に、点検で誤りの指摘がありました。指摘を反映して、文章を直してください。

入力ファイルの内容:

- `project` … 志望校・試験の型・目標の高さ。
- `chapter` … 章の題。
- `target` … `chapter`(章の本文)または `supplement`(章に追記する補足)。
- `sections` … いまの文章。`target` が `chapter` のときは `intro`・`points`・`pitfalls`、`supplement` のときは `supplement`。
- `figures` … いまの図(`id`、`svg`、`caption`)。本文中の `[[図のID]]` の行に置かれる。
- `issues` … 点検の指摘の一覧(`section`、`quote` = 問題のある箇所、`problem` = 何が誤りか、`fix` = 直し方)。
- `examples` … この章の例題(検算済み。直さない。本文と食い違わないようにするための参考)。

## 直し方

- 指摘を1件ずつ確かめる。指摘が正しければ、その箇所を直す。**指摘のほうが誤っている** と確かめられたときは、その箇所は直さなくてよい。
- 指摘の無い箇所は、**書き換えない**(文章を整え直したり、長さを変えたりしない)。直した結果つじつまが合わなくなる前後の文だけ、合わせて直す。
- 指摘のあった部分(`section`)は、直したあとの **全文** を書く(`intro`・`points`・`pitfalls`・`supplement` のうち、指摘のあったもの)。指摘の無かった部分は null にする。
- 図を直す必要があるときだけ、`figures` に直した図を **すべて**(直していない図も含めて)書く。図を直さないなら、`figures` は空の配列にする(いまの図をそのまま使います)。
- 文章は Markdown、数式は LaTeX(`$...$`、`$$...$$`)。見出しは `###` から。
- 正確さを最優先する。直した式・数値は、計算し直して確かめる。
