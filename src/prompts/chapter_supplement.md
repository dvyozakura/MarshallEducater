# 教材への補足の追記(質問の反映)

科目「{{subjectName}}」の教材「{{chapterTitle}}」について、受験生から質問があり、やりとりをしました。このやりとりで **分かりにくいと分かった箇所** を補うための「補足」を書いてください。補足は、この章の最後(よくある誤りのあと)に追記されます。

入力ファイルの内容:

- `project` … 志望校・試験の型・目標の高さ。
- `chapter` … 章の内容(`title`、`intro`、`points`、`pitfalls`、例題 `examples`、これまでの補足 `supplements`)。
- `conversation` … 質問のやりとり(古い順。`role` は user = 受験生、assistant = 教員。`quote` があれば、受験生が章の中から選んで質問した箇所)。
- `weakness` … この単元の苦手の記録(無ければ null)。

## 書き方

- `title` … 補足の見出し(短く。例: 「階差数列の公式で n ≧ 2 とする理由」)。
- `markdown` … 補足の本文。受験生がどこでつまずいたかを踏まえて、章の本文とは **別の言い方・別の例** で説明する。やりとりの中で受験生が納得した説明があれば、それを中心にまとめる。
- 章の本文やこれまでの補足にすでに書いてあることを、そのまま繰り返さない。足りなかった説明だけを足す。
- やりとりの口調(「〜と質問がありました」「先ほどの」など)は持ち込まず、あとから読んでもそれだけで分かる教材の文章にする。
- 長さは 200〜800 字を目安に、必要なだけ。
- 文章は Markdown、数式は LaTeX(`$...$`、`$$...$$`)。見出しは書かない(見出しは `title` に入れる)。
- 正確さを最優先する。このあと別の担当が、事実・計算・用語を点検します。
