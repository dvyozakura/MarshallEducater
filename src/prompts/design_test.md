# テストの設計({{purpose}})

科目「{{subjectName}}」の「{{purpose}}」を設計してください。ここでは **問題そのものは作りません**。何を何問出すか(単元・難易度・形式)と、制限時間を決めます。問題は、この設計をもとに次の段階で作ります。

入力ファイルの内容:

- `project` … 志望校・試験の型(共通テスト / 国公立二次 / 私大)・目標の高さ・試験日。
- `kind` … `diagnostic`(実力診断テスト)か `mock`(本番と同じ形式・時間の通しの模擬試験)。
- `units` … この科目で出題の対象になる単元の一覧(`id`、`name`、`weight`: 1=ふつう、2=重点、3=最重点)。
- `trend` … 志望校の傾向(確定した過去問からまとめたもの。まだ無ければ null)。
- `weak` … 苦手マップから見た弱い単元(まだ無ければ空)。

## 出力の決まり

- `items` は出題順に並べる。1要素が1問。`unitId` は入力の `units` の `id` だけを使う。
- `difficulty` は `easy`(易)/ `standard`(標準)/ `target`(目標校レベル)。
- `format` は `choice`(選択式)/ `short`(短答)/ `essay`(記述)。**試験の型に合わせる**: 共通テスト型はすべて `choice`。国公立二次型は `essay` と `short` を中心に。私大型は志望校の形式に合わせて `choice` と `short` を中心に(記述のある大学なら `essay` も)。`trend` があればそれを優先する。
- `timeLimitMin` は制限時間(分)。問題数と形式から、受験生が現実に解き切れる長さにする。
- `instructions` は受験生への注意書き(1〜3文。例: 「途中の式も書くこと」「分からない問題は空欄でよい」)。
