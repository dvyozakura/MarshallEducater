# ページ画像の読み取り({{modeLabel}})

科目「{{subjectName}}」の資料「{{title}}」({{kindLabel}})のページ画像を読み、あとで使いやすい形に書き起こしてください。

入力ファイルの `pages` に、今回読むページの一覧があります。各ページの `image`(PNG)を Read ツールで **必ず1枚ずつ開いて** 読んでください。`text` があるページは、PDF から取り出した文字です(数式や段組みは崩れていることがあるので、画像を正とし、文字の確認にだけ使う)。

{{modeInstructions}}

## 書き起こしの決まり

- `body` は Markdown。数式は LaTeX で、文中は `$...$`、独立した式は `$$...$$`。
- 縦書きの文章は、読む順(右の行から左へ)に横書きへ直す。ルビは `漢字(よみ)` と書く。傍線部は `<u>` を使わず **太字** にし、「傍線部A」などの記号があれば添える。
- 原文を勝手に直さない。誤植と思われる箇所もそのまま写し、`uncertain` に書く。
- `number` は紙面どおりの番号(例: `第1問 (2)`)。`major` は大問、`minor` は小問の番号(無ければ空文字)。
- `points` は配点が書いてあれば数値、無ければ null。
- 選択肢がある問題は `choices` に1つずつ入れ(記号は付けたまま)、`answerFormat` を `choice` にする。短い答えを書く問題は `short`、説明や論述・証明は `essay`、判断できなければ `other`。
- `unit` は、入力の `units`(この科目の単元の一覧)から最も近いものの `id` を書く。当てはまるものが無ければ空文字。
- `pages` は、その問題が載っているページ番号。
- 図・グラフ・地図・表・資料の図版は `figures` に入れる。`page` はページ番号、`bbox` は図の範囲(ページの左上が (0,0)、右下が (1,1)。`x`,`y` は左上の角、`w`,`h` は幅と高さ。少し広めに取る)、`description` は図を見なくても問題が解けるくらい詳しい文章での説明(軸・目盛り・数値・位置関係)。
- **読み取りに自信がない箇所** は、推測で埋めずに `uncertain` に入れる。`text` はその箇所の文字列(`body` に書いたとおり)、`reason` は理由(例: 「かすれている」「手書きで 1 か 7 か判別できない」)。
- 長い問題文(長文読解など)は省略せず全文を書き起こす。

## 分けて読むときの決まり

- 資料は数ページずつに分けて読んでいます。入力の `previousTail` が null でなければ、それは **前のページ群の最後の問題** の番号と本文の末尾です。
- 今回の最初のページが、その問題の続き(問題文や小問が前から続いている)で始まる場合は、最初の要素の `continuesFromPrevious` を true にし、**続きの部分だけ** を書く(アプリが前の問題とつなげます)。それ以外は false。
- ページ番号・表紙・注意書きだけのページからは、問題を作らない(問題が1つも無ければ `problems` は空の配列)。
