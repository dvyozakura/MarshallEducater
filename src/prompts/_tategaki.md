## 国語(縦書き)の書き方
ME_TATEGAKI: write
この科目は国語で、アプリは本文・設問・選択肢・教材の本文を **縦書き** で表示・印刷します。文章(Markdown)の中では、次の記法だけを使ってください。ほかの独自の記号・HTML は使わないでください。

- ルビ: `{漢字|かんじ}`
- 傍線(記号つき): `{{傍線:ア|本文}}`。波線は `{{波線:a|本文}}`、二重傍線は `{{二重傍線:1|本文}}`。設問では「傍線部ア」のように記号で指す。
- 傍点: `{{傍点|本文}}`
- 空欄: `{{空欄:A}}`(字数を示すなら `{{空欄:A:5}}`)。設問では「空欄 A」と書く。
- 段落番号: 段落の頭に `{{段落:1}}`
- 語注: 本文で `{{注:1|語}}`、本文の最後に `{{注記:1|説明}}` を1行ずつ。
- 漢文は、行の頭の `:::漢文 白文` / `:::漢文 訓読文` / `:::漢文 書き下し文` で始め、行の頭の `:::` で閉じる。訓読文の中では、字のあとに送り仮名 `[_ビテ]`、返り点 `[^レ]` `[^一]` `[^二]` `[^上]` `[^下]` `[^一レ]` を書く(例: `登[_リ][^レ]山[_ニ]`)。再読文字は `{{再読:未|いまダ|ず}}`(右の読み|左の読み)。ふりがなはルビの記法。
- 数字は漢数字を基本にする(年号・番号など2桁までの算用数字は縦中横で表示される)。英字は必要なときだけ。
- 本文には、既存の文学作品・評論・過去問の文章を引用せず、この問題のために書き下ろした文章を使う(古文・漢文も、作った文章でよい)。
- 解説・採点の所見・質問への答えは横書きで表示されるので、記法は引用のときだけ使えばよい。

## 国語(縦書き)の読み取り方
ME_TATEGAKI: read
この科目は国語で、ページは **縦書き** のことが多いです。
- 読む順: 行は上から下へ、行の並びは右から左へ。段組みがあれば、上の段の右から左 → 下の段の右から左。
- 本文は、次の記法で写してください(アプリが縦書きで表示します)。ほかの独自の記号・HTML は使わないでください。
  - ルビ: `{漢字|かんじ}`
  - 傍線と記号: `{{傍線:ア|傍線の引かれた本文}}`。波線は `{{波線:a|本文}}`、二重傍線は `{{二重傍線:1|本文}}`。
  - 傍点: `{{傍点|本文}}`
  - 空欄: `{{空欄:A}}`(枠の大きさから字数が分かれば `{{空欄:A:5}}`)
  - 段落番号: 段落の頭に `{{段落:1}}`
  - 語注: 本文で `{{注:1|語}}`、注の文は `{{注記:1|説明}}`
  - 漢文: 行の頭の `:::漢文 白文` / `:::漢文 訓読文` / `:::漢文 書き下し文` で始め、行の頭の `:::` で閉じる。訓読文では、字のあとに送り仮名 `[_ビテ]`(字の右下の小さなカタカナ)、返り点 `[^レ]` `[^一]` `[^二]` `[^上]` `[^下]` `[^一レ]`(字の左下の記号)を写す。再読文字は `{{再読:未|いまダ|ず}}`。
- 2桁の数字が横に並んで組まれていても(縦中横)、半角数字で写す。
- 記号・返り点がかすれて読めないときは、推測で写して `uncertain` に理由を書く。

## 国語(縦書き)の記法について
ME_TATEGAKI: understand
この科目は国語で、問題・答案・教材の文章は次の記法を含むことがあります(アプリが縦書きで表示します)。意味を読み取って扱ってください。
- `{漢字|かんじ}` はルビ。`{{傍線:ア|本文}}` は記号アの傍線部(`波線`・`二重傍線` も同様)。`{{傍点|本文}}` は傍点。`{{空欄:A}}` は空欄 A。`{{段落:1}}` は段落番号。`{{注:1|語}}` と `{{注記:1|説明}}` は語注。
- `:::漢文 白文` / `訓読文` / `書き下し文` … `:::` は漢文。訓読文の `字[_ビテ]` は送り仮名、`字[^レ]` は返り点、`{{再読:未|いまダ|ず}}` は再読文字。
- 解説・所見・質問への答えは横書きで表示されます。本文を引用するときは同じ記法を使ってよいが、使わなくてもよい。記法を使うなら、閉じ忘れが無いように書く。
