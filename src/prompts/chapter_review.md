# 教材の点検

科目「{{subjectName}}」の教材「{{chapterTitle}}」の文章を、**書いた人とは別の担当として** 点検してください。目的は、受験生が誤ったことを覚えないようにすることです。

入力ファイルの内容:

- `project` … 志望校・試験の型・目標の高さ。
- `chapter` … 章の題。
- `target` … `chapter`(章の本文の点検)または `supplement`(章に追記する補足の点検)。
- `sections` … 点検する文章。`target` が `chapter` のときは `intro`(導入)・`points`(要点)・`pitfalls`(よくある誤り)。`supplement` のときは `supplement`(追記する補足)。
- `examples` … この章の例題(問題・答え・解き方)。別の手順で検算済みなので **点検の対象ではない**。本文が例題と食い違っていないかを見るための参考。
- `context` … `target` が `supplement` のとき、章の要点(補足が章の内容と食い違っていないかを見るための参考)。それ以外は null。

## 点検すること

1. **事実** … 定義、定理・公式、法則、年号、人名、因果関係、文法の規則などに誤りが無いか。
2. **計算** … 本文中の式変形・数値・具体例の計算を、自分で計算し直して確かめる。
3. **用語** … 用語・記号の使い方が正しく、章の中で一貫しているか。高校の学習範囲で通じる言い方か。
4. 例題(`examples`)の答え・解き方と、本文の説明が食い違っていないか。

## 書き方

- 誤りを見つけたら、`issues` に1件ずつ書く:
  - `section` … どの部分か(`intro` / `points` / `pitfalls` / `supplement`)。
  - `quote` … 問題のある箇所を、本文からそのまま短く抜き書きする。
  - `problem` … 何が誤りか。根拠(正しい定義や、計算し直した結果)も書く。
  - `fix` … どう直せばよいか(正しい文や式)。
- **誤りだけ** を書く。文章の好み、もっと詳しく書けるといった改善の提案、言い回しの違いは指摘しない。確信が持てないものは書かない。
- 誤りが無ければ、`issues` は空の配列にする。無理に指摘を作らない。
- `comment` に、全体の所見を一言書く(例: 「誤りは見つからなかった」「計算の誤りが1件」)。
