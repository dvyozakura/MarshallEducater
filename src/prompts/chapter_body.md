# 教材の章の本文

科目「{{subjectName}}」の体系的な教材(受験生が教科書の代わりに、最初から順に読んで学ぶテキスト)の **第{{chapterNo}}章「{{unitName}}」** の本文を書いてください。

章の構成は「導入 → 要点 → 例題(解答・解説つき) → よくある誤り → 確認問題」です。このうち、あなたが書くのは **導入・要点・よくある誤り** と、**例題のねらい** です。例題と確認問題そのものは、このあと別の手順で作って検算します(ここでは書かない)。

入力ファイルの内容:

- `project` … 志望校・試験の型・目標の高さ・試験日。
- `chapter` … この章(`no`、`title` = 上位の単元を含む名前、`unitName`)。
- `previousChapter` / `nextChapter` … 前後の章の題(無ければ null)。前の章の内容は学んだものとして使ってよい。次の章の内容は先取りしない。
- `toc` … 教材全体の章の題の一覧(ほかの章と内容が重ならないようにするための参考)。
- `spec` … この章の厚さ。
  - `thickness` … `thick`(詳しい)/ `standard`(標準)/ `thin`(要点中心)。
  - `chars` … 導入・要点・よくある誤りを合わせた長さの目安(字)。
  - `style` … 書き方の指示。**必ず従う**。
  - `examples` … このあと作る例題の一覧(易しい順。`difficulty` と `format`)。
- `unlearned` … true なら、受験生はこの単元をまだ習っていない。前提となる知識の確認から始め、用語は初めて出るたびに定義する。
- `weakness` … この単元の苦手の記録(習熟度 `mastery` 0〜100、解いた数 `attempts`、ミスの種類ごとの回数 `mistakes`)。診断前で記録が無ければ null。
- `mistakes` … この単元で受験生が実際に間違えた問題と、採点時の所見(無ければ空)。
- `trend` … 志望校の傾向(出題形式、頻出単元、難易度の所見)。無ければ null。
- `note` … この単元について前に作った授業ノート(無ければ null)。内容の参考にしてよいが、写さずに書き直す。
- `previous` … 作り直しのとき、前の版の本文(`intro`、`points`、`pitfalls`)。良い部分は残し、いまの `spec` と苦手の記録に合わせて直す。無ければ null。

## 書くもの

- `intro`(導入)… この章で何ができるようになるか、前の章とどうつながるか、志望校の入試でどう問われるか(`trend` があれば、それに基づく。無ければ試験の型から一般的に)。数行〜十数行。
- `points`(要点)… 定義・公式・定理・重要事項を、**意味・理由・使いどころ** と一緒に、学ぶ順に書く。丸暗記の一覧にしない。小見出し(`###`)で区切り、必要なら短い具体例(1〜2行で済むもの)を添える。
- `pitfalls`(よくある誤り)… 受験生がしがちな間違いを「誤り → なぜ起きるか → 防ぎ方」で箇条書きにする。`weakness`・`mistakes` があれば、この受験生の実際のミスの種類に合わせる。
- `exampleFocus`(例題のねらい)… `spec.examples` と **同じ数・同じ順** で、各例題で身につけさせたいことを1文ずつ(例: 「階差数列から一般項を求める手順を、和の公式の適用範囲に注意して身につける」)。`points` で説明した内容だけで解けるねらいにする。
- `figures`(図)… 図が無いと分かりにくいところだけ。SVG で描き(`<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 幅 高さ">` で始め、線・文字は黒、幅 400 以内、スクリプトや外部の画像は使わない)、`id`(例: `fig1`)と `caption`(図の説明。図が無くても意味が通じる文)を付ける。本文の中で図を置きたい場所に、その行だけで `[[fig1]]` と書く。図が要らなければ空の配列。

## 決まり

- **正確さを最優先する。** 公式・事実・年号・用語・計算は、確かめてから書く。あいまいなこと、自信のないことは書かない。このあと別の担当が、事実・計算・用語を点検します。
- 文章は Markdown、数式は LaTeX(`$...$`、`$$...$$`)。`intro`・`points`・`pitfalls` の中に `#` や `##` の見出しは書かない(小見出しは `###` から)。
- 厚さ(`spec.thickness`・`spec.chars`・`spec.style`)を守る。得意な単元(thin)に長い説明を書かない。苦手・未習の単元(thick)では、途中の理由を省かない。
- 実在の教科書・参考書・入試問題の文章を写さない。自分の言葉で書く。英語・国語の例文も自分で作る。
- ほかの章(`toc`)の内容に深入りしない。必要なら「第N章で扱う」と一言触れる程度にする。
